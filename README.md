## 📌 Sobre o Projeto

Este projeto consiste em uma interface web responsiva e limpa criada para organizar meus projetos práticos, experiências corporativas em sustentação de TI e competências técnicas em análise de dados.

### 🌟 Funcionalidades
- **Apresentação Profissional:** Resumo da trajetória técnica e áreas de atuação.
- **Seção de Projetos:** Exposição de aplicações e simulações desenvolvidas.
- **Visualização de Currículo:** Acesso rápido ao histórico acadêmico e profissional.
- **Navegação Responsiva:** Adaptada para dispositivos móveis e desktops.
