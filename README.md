# Sobre

Este repositório contém o meu portfólio profissional, publicado no GitHub Pages. O conteúdo do site está em inglês e reúne:

- Apresentação com cargo atual, principais competências e links de contato
- Currículo online com experiência, formação, certificações e habilidades
- Projetos selecionados, cada um com stack, descrição, repositório e demonstração
- Prévia ilustrativa de um dashboard de operações de TI, com dados sintéticos

O site não usa frameworks, build ou dependências: apenas HTML e CSS.

## Principais recursos

- Página inicial com foto, cargo e competências em destaque
- Currículo web (`cv.html`) com versão em PDF para download
- Página de projetos com links para código e demonstração online
- Layout responsivo para desktop, tablet e smartphone
- Favicon com foto de perfil
- Estilos de impressão no currículo

# Executando localmente

Não é necessário instalar dependências.

Clone o repositório:

```bash
git clone https://github.com/Henriquedu/resume.git
```

Entre na pasta:

```bash
cd resume
```

Abra o arquivo `index.html` em qualquer navegador moderno.
